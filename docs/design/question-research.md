# Question research

Add “Tìm hiểu thêm” below the explanation in practice feedback and result review, for both correct and incorrect answers. Exam questions keep feedback hidden until result review. The supplied quiz screenshot is the insertion reference; the existing shared bottom-sheet system determines the new surface.

Use existing green/mint tokens, platform typography, 24px heading, 28px top corners, gray handle and subtle mint waves. The sheet shows question number, full question and quiz answer before research. Reuse the animated robot/dots indicator, including reduced-motion support. Content scrolls with safe-area padding and a 640px maximum width. Loading, result, no-source, network-error/retry and connection-change states are covered. Closing a pending sheet never renders a late result.

The authenticated `/api/research` endpoint accepts only quiz ID and question index, then loads the persisted question. AI selects a topic; the server retrieves at most three introductory extracts from Vietnamese Wikipedia and asks AI to explain the question using relevant sources. Only retrieved sources cited by the model are returned. Missing sources are explicitly labeled unverified. This is Wikipedia research, not a general web search. It does not alter quiz answers, generation jobs or attempts. External input is treated as data, and model-supplied URLs are never fetched. At most two research calls run concurrently; calls have bounded timeouts and no automatic retry. Dismissing the sheet ignores the response but does not cancel server research.

Acceptance: button appears after practice answers and in result review; opening sends the selected question ID/index; loading animation ends in content or an explicit retryable error; sources match retrieved pages; connection changes invalidate pending results; no overflow at 320/393/1280 widths.
